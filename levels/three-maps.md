# V1 map set: research and rationale (2026-11-18)

Per-map specs now live in maps/ (README, kitchen, stairwell, box-fort). This doc keeps the research only. Earlier per-map numbers here used W 400 and checkpoints every 4 ramps; superseded by decisions.md (W 460, checkpoints ~30 s) and the maps/ files.

## CS surf archetypes
| Archetype | Reference maps | Core pleasure | Core challenge |
|---|---|---|---|
| Linear flow | utopia, mesa, aircontrol_ksf, surf_me | Rhythm, vista, flow state | Consistency over a full run |
| Staged ladder | kitsune, beginner, rookie | Escalation, per-stage PBs | Each stage adds one new demand |
| Speed / big transfer | pre-gained style maps, mesa drops | Raw velocity, long air | Carrying enough speed; air control |
| Tech | higher-tier kitsune stages, T3+ | Mastery, precision | Narrow, short ramps, fast direction changes |
| Bonus | utopia/kitsune bonuses | 10-30 s micro-challenge | One trick, isolated |
| (Skip) Combat / trick | ski_2, greatriver | Social chaos, freestyle | N/A for v1 |

## What evergreen maps share (utopia, kitsune, mesa: ~10+ years on top)
1. Legible: next ramp visible before you leave the current one.
2. Rhythm: regular ramp/air cadence.
3. Short loop: classic linear records mostly 10-60 s.
4. Forgiving floor, precise ceiling: checkpoints to finish, timer to master.
5. Coherent aesthetic identity.
6. Escalation (kitsune teaches by ramping difficulty per stage).
7. Speed payoff: a money ramp after a drop.

Caveat: sources were listicles and record archives; the "why" is synthesis, not cited design theory.

## Set logic
| | Kitchen (T1) | Stairwell (T2) | Box Fort (T3, enclosed) |
|---|---|---|---|
| Dominant skill | reading/rhythm | energy + air | precision |
| Fail mode | none (time loss) | too slow | too fast |
| Width | 600 -> 460 | 460 -> 370 | 400 -> 310 |
| Turn R | 6000-7000 | 5000-8000 | 1800-2500 |
| Speed band | 900-1600 | 1200-2200 | 800-1400 |
| Air share | ~30% | ~40% | ~20% |
